# 50 Best Free Alternatives to Adobe Creative Cloud

An Astro static-site starter for a curated directory of free and freemium creative tools.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Cloudflare's current documentation supports Astro deployment. For a static Astro site, build to `dist` and deploy through Cloudflare. Cloudflare currently documents both Pages and Workers workflows; its current documentation recommends Workers for new projects.

For an existing Pages project, the documented build command is `npm run build` and the build directory is `dist`.

## Monetization checklist

- Verify each company's current affiliate program directly.
- Do not claim a commission rate unless the network/merchant confirms it.
- Replace official URLs with approved affiliate URLs only after approval.
- Add a clear affiliate disclosure.
- Check each community's self-promotion rules before posting.
